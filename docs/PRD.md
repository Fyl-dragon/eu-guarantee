## 1. 一句话定位

> 帮在欧盟销售实物商品的商家，**一次配置**就展示法定的欧盟保证告知与 GARAN 耐用性标签，
> 并**真正把商业保证声明交付给买家**——竞品只做展示，我们交付完整闭环。

## 2. 背景与问题

### 2.1 时间窗口

- **2026-09-27** 起，向欧盟消费者销售消费品的卖家**必须**展示"统一告知"（harmonised notice）。
- 提供自愿耐用性商业保证（免费、整机、>2 年）的生产者**必须**使用 **GARAN** 标签，
  并以可留存形式向消费者提供**商业保证声明**。
- 今天是 **2026-10-22**，生效 25 天。商家正在找方案。

### 2.2 竞品的真实缺口（桌面假设 vs 四家实测）

#### 2.2.1 三个桌面假设，两个被实装推翻

| #   | 原假设                   | 判定                    | 证据                                                                                   |
| --- | ------------------------ | ----------------------- | -------------------------------------------------------------------------------------- |
| 1   | 没人交付**商业保证声明** | ✅ **存活（4/4 全空）** | Business 档只有 reminder；四家全文检索 `guarantee statement` = 0 命中                  |
| 2   | 没人做**合规证据/审计**  | ◐ **部分推翻**          | Consentico 完整；EU Warranty 仅 self-check；Pandectes 未见                             |

**⚠️ 已弃用的表述**：

- ❌ "我们做硬拦截，竞品不做" —— **EU Warranty 已做了三前提勾选门槛**。
  照原样写进 App Store 文案会被直接指出不实。

### 2.3 我们**不做**什么

- ❌ 不拼"免费档更全" —— **必须持平**。Consentico 免费档已给 24 语言 + 无限 GARAN + 四处位置；
  比他更窄就拿不到安装（详见 6.4）。
- ❌ 不拼"价格更低" —— EU Warranty 年付 €49.90（≈$4.2/月）、Pandectes $9/月已是地板。
- ❌ 不拼"合规证据更全" —— Consentico 已有完整 audit log。
- ✅ **只拼两件事**：声明交付（C1–C5）、B0 精确四项（D-1..D-4）。
- ✅ **必须做到三件事以不输**：四处位置、24 语言、免费档不卡功能。

## 3. 目标客户（ICP）

### 3.1 主要 ICP：有自有耐用性保证的欧盟卖家

| 特征   | 说明                                              |
| ------ | ------------------------------------------------- |
| 销售地 | 在欧盟有销售（有 market 或 EU locale）            |
| 商品   | 实物消费品（非数字、非礼品卡）                    |
| 关键   | **提供自己的耐用性保证**（≥3 年，免费，覆盖整机） |
| 规模   | 中小型，无专职法务                                |
| 现状   | 要么没做、要么用了竞品但只得到"一个徽标"          |

**为什么"有自有保证"是关键**：只有这批人同时需要 notice（人人要）+ GARAN（条件触发）+ 声明（他们才有内容可写）。

### 3.2 次要 ICP：只做 notice 的纯合规需求

只用 F1–F2（全站 notice），免费档即可满足。**这是获客漏斗，不是变现对象。**

### 3.3 明确不服务的对象

- 纯数字商品店（法规排除）
- 纯 B2B 批发（B2B 买家不适用消费者保护）
- 服务型商家
- 需要法律意见的商家（我们不做）

## 6. 核心设计决策

### 6.1 声明交付用**订单状态页扩展**，不发邮件

| 方案                       | PII          | PCD         | 交付周期            |
| -------------------------- | ------------ | ----------- | ------------------- |
| 邮件发送声明               | 需买家 email | **Level 2** | 数周审批 + 合规文档 |
| **订单状态页扩展**         | 不需要       | **不需要**  | 立即可用            |
| 公开可打印页（带签名链接） | 不需要       | 不需要      | 立即可用            |

**决策：采用订单状态页 + 公开可打印页。** 这是把"声明交付"从"要审批的重活"变成"一周能做完的活"的关键。

### 6.2 零主题侵入

全部通过 Theme App Extension：

- **app embed**（全站）→ 承载 F1 全站 notice
- **app block**（商品页）→ 承载 F3 GARAN 标签
- **customer account UI extension**（订单状态页）→ 承载 F7 声明

商家不需要改任何主题代码，卸载后零残留。

### 6.3 语言策略

- **notice / GARAN 文案**：使用欧盟委员会**官方 vector 文件**，不自行翻译。
- **判定顺序**：订单语言（声明）→ store locale（notice）→ 手动覆盖。
- 免费档限制语言数量，付费解锁全部 24 种。

### 6.4 免费档与定价（v1.2：数字不变，风险已记录）

**定价原则**：**免费档不卡功能**（四家中三家已把功能免费），付费墙只建在**对手没有的能力**上。

|                                       | Free $0  | Starter **$12/月** | Pro **$24/月** |
| ------------------------------------- | -------- | ------------------ | -------------- |
| 四处位置 notice                       | ✅       | ✅                 | ✅             |
| 24 语言（官方 artwork）               | ✅       | ✅                 | ✅             |
| GARAN 数量                            | **无限** | 无限               | 无限           |
| 折叠展示                              | ✅       | ✅                 | ✅             |
| 排除规则                              | ✅       | ✅                 | ✅             |
| **B0 精确四项（D-1..D-4）**           | **✅**   | ✅                 | ✅             |
| 配置概览（已配/未配/不合格）          | ✅       | ✅                 | ✅             |
| 审计最简版（快照 + 变更 + 一致性）    | ✅       | ✅                 | ✅             |
| 逐变体标签                            | ❌       | ✅                 | ✅             |
| 批量 CSV + 组应用                     | ❌       | ✅                 | ✅             |
| **商业保证声明 C1–C5**                | ❌       | ✅                 | ✅             |
| **声明交付（订单状态页 + 可打印页）** | ❌       | ❌                 | ✅             |
| 审计导出（CSV + dated PDF）           | ❌       | ❌                 | ✅             |
| 保修登记                              | ❌       | ❌                 | ✅             |
| **商品数上限**                        | **无限** | 无限               | 无限           |
| 支持                                  | 邮件     | 邮件               | 优先           |

**为什么把 B0 精确四项放进免费档**：

- 成本极低（一条校验 + 一条日志），边际成本近零。
- 它是**信任锚点**：免费用户也能感知"这家更严谨"，直接影响评论与口碑。
- 竞品做错了，我们在最便宜的档位就能形成对比。
- **注意**：这不再是"竞品完全没有"的能力 —— EU Warranty 已做入口门槛，
  我们主张的是它**没做全**的四条（整数校验 / 入口不渲染 / 状态一致 / 拒绝留痕）。

**为什么 $12 / $24**：

- Consentico 是 $4.99 / $9.99 / $24.99。$12 卡在 Lite 与 Pro 之间，
  卖的是他们**没有**的能力（逐变体 + 批量 + 声明），不是"更多商品数"。
- $24 略低于 $24.99，卖声明交付 + 审计导出 + 登记，守住 $25 心理线。
- **不做年付折扣的首版**（减少计费复杂度），P1 再加。

#### 6.4.1 ⚠️ 价格地板风险（v1.2 新增，四家实测后才发现）

| 家                  | 最低付费档    | 折合月成本   | 与 $12 的倍率          |
| ------------------- | ------------- | ------------ | ---------------------- |
| **EU Warranty Pro** | **€49.90/年** | **≈$4.2/月** | **$12 是它的 ≈2.9 倍** |
| Consentico Lite     | $4.99/月      | $4.99        | 2.4 倍                 |
| Pandectes Plus      | $9/月         | $9           | 1.33 倍                |

**判断**：卖的东西不同（声明 vs 标签），所以不必然要改价。
但商家感知的是"同类工具的价格"，**$12 在货架上会显得最贵**。

**决策（本轮）**：**不改数字**。理由：

1. 在拿到第一批商家对话之前改价，只是换一个猜测。
2. 降价会削弱"声明是重活"的价值感知，与差异化 1 冲突。
3. **V1 必须验证**（PRD 开放问题 Q5 + Q6）：给对方看 reminder 与 statement 的对比，
   问"这个差价你愿意付吗"。

**若 V1 显示价格是主要阻力**，三个备选动作（不改产品，只改包装）：

- 降 Starter 到 $9、Pro 到 $19，让"声明"成为 $9 档的卖点
- 保留 $12 但把年付折扣提前到首发（$120/年 ≈ $10/月）
- 把商品数上限引入 Free（如 25 个），让规模化商家自然升级

#### 6.4.2 与三家免费档策略的对比

| 家              | 免费档卡点                  | 我们的位置                                        |
| --------------- | --------------------------- | ------------------------------------------------- |
| Consentico      | 视觉形态（仅 Clean）+ 水印  | 我们免费给折叠；卡声明                            |
| **EU Warranty** | **商品数 15**               | **我们不卡商品数** → 对 15–200 SKU 的店是真实差异 |
| **Pandectes**   | **语言 1 种**（24 种要 $9） | **我们免费给 24 种** → 跨境卖家在它那不可用       |
| Dyrect          | 100 credits                 | 不同赛道                                          |

**为什么不做"3 语言 / 10 商品"式免费档**：
Consentico 免费档给 24 语言 + 无限 GARAN。若我们更窄，商家会直接选它，
我们连"被试用"的机会都没有。**免费档的作用是拿到安装，不是变现。**

### 6.5 产品原则：不允许出现不合规状态

这条原则来自四家实测缺陷（见 2.2.2），是 v1 的硬约束：

1. **不满足法定前提时，拒绝保存，不只警告。** 前端禁用 + 服务端二次校验。
2. **被排除的商品，GARAN 入口不渲染。** 不给"警告后仍能操作"的机会。
3. **任何被拒的尝试写入审计。** 从"我不知道"变成"我防住了"。
4. **三处状态必须一致。** notice 排除状态 / GARAN 状态 / 审计记录不得互相矛盾。
5. **批量与导出必须同一套校验。** 单条 / 批量 / CSV / API / PDF 导出共用
   `validateGaranEligibility()`；任一不合法则整批拒绝，不做部分成功。

**验收关联**：T3 / T4 / T4b / T4c / T5 / T5b / T5c / **T5d / T5e / T12**
（见 `../../market-research/18-requirement-matrix.md` 第八节）。

### 6.6 竞争位置辨析：我们的声明 vs Consentico Business 的 reminder（v1.2 新增）

**这一节是为了防止上架文案被指不实，必须写清。**

实测确认：Consentico Business 档的 `Guarantee reminder on the thank-you and order status pages`
（`17` 附录 A1 `27.png`）。**它的位置与我们的 F7 完全重叠。**

|          | Consentico Business                  | **我们 F7**                       |
| -------- | ------------------------------------ | --------------------------------- |
| 位置     | 订单状态页 + thank-you 页            | 订单状态页 + 可打印页（**相同**） |
| 内容     | 一句"你有权主张保证"式的**提醒**     | **C1–C5 五项合同条款**            |
| 可留存   | 依赖页面/邮件                        | **明确提供"保存为 PDF"**          |
| 绑定商品 | 不绑定                               | 绑定订单内具体商品/型号（C4）     |
| 价格     | $24.99/月（Business 档全部功能之一） | $12 起（Starter 含声明）          |

**允许的表述**：

> "Competitors show a reminder that you have a guarantee. We deliver the actual

**诚实的边界**（必须写进官方 FAQ 或 listing 备注）：
Consentico Business 档的实际 reminder 渲染**未实装验证**。
若它实际上包含 C1–C5，本节的差异化结论需要整体重写。

## 9. 文案红线

产品内所有文案**禁止**出现：

- "guaranteed compliant" / "legally compliant" / "保证合规"
- "我们确保你符合法规"
- 任何形式的"我们的声明具有法律效力"
- ❌ **"We are the only app that..."**（除非 V1 已确认竞品确实没有）
- ❌ **"No other app does this at all."**（同上；C1–C5 的空白只能从定价页文字推断）

**必须**出现的声明：

> This app helps you display the EU legal guarantee notice and GARAN label,
> and deliver a commercial guarantee statement. It is a display and delivery tool,
> not legal advice.

**允许的差异化表述**（见 6.6）：

> Competitors show a reminder that you have a guarantee. We deliver the actual
> statement — the five items the regulation requires.
