## 结论：唯一候选是「EU 保证展示 + 商业保证声明 + 保修登记」

**关键时间点**：欧盟统一保证告知制度于 **2026-09-27** 强制生效，距今 25 天。

**概念澄清**：GARAN **不是法规名**，而是"统一标签"的标题文字。
法规是 **Directive 2011/83/EU**（经 **Directive (EU) 2024/825** 修订）+
实施细则 **Implementing Regulation (EU) 2025/1960**。两个独立制度：

|          | 统一告知（notice）           | GARAN 标签（label）              |
| -------- | ---------------------------- | -------------------------------- |
| 性质     | 法定符合性保证说明           | 自愿耐用性商业保证标记           |
| 谁必须做 | **所有**在欧盟卖消费品的卖家 | **仅**提供自愿耐用性保证的生产者 |
| 位置     | **店铺层**，线上必须彩色 RGB | **商品/型号层**                  |
| 可编辑   | 统一设计                     | 仅年数 / 品牌 / 型号；其余锁定   |

## 官方素材已实测（M2 完成，2026-10-22 复核）

委员会官方 vector 文件可下载：24 语言 SVG（27MB）、PNG/JPG（3.9MB）、PDF 通知、
GARAN 标签（彩色/黑白/嵌套）。**已知坑：PNG 包缺英语**，SVG 与 PDF 有。

**实测数据（`../../market-research/21-asset-verification.md`）**：

| 项 | 结果 |
| --- | --- |
| notice SVG | raw 485–686 KB，**gzip 54–79 KB（平均 62）** |
| notice viewBox | `0 0 595.28 841.89` = **A4**，同一份文件可屏幕 + 印刷 |
| GARAN 完整版 | raw 294 KB / **gzip 27 KB**，3 个 `<text>` |
| GARAN 嵌套版（折叠） | raw 8.3 KB / **gzip 3.3 KB**，**仅 1 个 `<text>`（年数）** |
| `years` 上限 | **99**（可用宽度 116.4 units；三位数 133.5 溢出） |
| 二维码 | 内嵌 498×498 PNG，显示 120pt，A4 打印够用 |
| **字体** | **未内嵌**（`@font-face` = 0，依赖系统 Inter）→ **A1 风险** |

**推翻的两个原决策**：
1. ~~预渲染 WebP~~ → 直接分发 gzip SVG（收益极小）
2. ~~3 个 text = 3 个可编辑字段~~ → 只有 `XX` 是值，brand/model 位置未明（**A2 风险**）

**可复用的竞品实现细节**（EU Warranty 的订单邮件 snippet，`17` 3A.7）：
语言回退链 `order.customer_locale` → `shop.locale` → 白名单 → `en`；
配置存 **shop metafield**，Liquid 只读，**零 API / 零 PII**。
